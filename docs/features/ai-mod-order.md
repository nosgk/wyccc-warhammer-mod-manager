# AI 智能排序

> 适用版本：`1.3.0` 及以后
> 入口：主界面底部「AI 智能排序」

## 功能说明

AI 智能排序会批量评估当前播放集中已启用 MOD 的建议位置，并给出：

- 建议顺序与每个 MOD 的当前位置、建议位置和移动方向。
- 每个建议的理由，例如依赖关系、类别顺序、资源覆盖或工坊评论中的兼容性提示。
- 同一 DB 表、脚本、本地化或 UI 资源被多个 MOD 覆盖时的冲突提示。
- 工坊必需物品缺失、AI 不可用等提示。

分析结果**不会自动应用**。只有点击「应用建议」后，才会写入当前播放集和加载清单。

## 数据来源

| 来源 | 用途 |
| --- | --- |
| 工坊元数据 | 标题、简介、作者、更新时间 |
| 工坊必需物品 | 作为软证据与警告；不会自动订阅或启用额外 MOD |
| 工坊评论 | 提取与加载顺序、兼容性、崩溃相关的摘要 |
| 本地元数据 | Pack 名、来源、更新时间、依赖、单位数据表 |
| Pack 索引 | DB 表、脚本、本地化、UI、变体资源 |
| 当前顺序 | 尽量少移动，保留用户手动调整的结果 |

## 使用方式

1. 在主界面启用需要评估的 MOD。
2. 点击底部「AI 智能排序」。
3. 选择排序基线：`当前顺序` 或 `默认规则`（Pack 文件名字节序，与新启用 MOD 的自动插入规则一致）。
4. 点击「开始分析」。
5. 在「分析过程」查看阶段、AI 局部/全局批次、重试与统计。
6. 查看当前顺序与建议顺序、理由和冲突。
7. 点击「应用建议」写入当前播放集；或在「历史建议」中查看、应用之前的记录。

分析期间可以继续浏览 MOD。关闭窗口会取消正在进行的分析。

## AI 与本地规则

- **启用 AI**：MOD 名称、简介摘要、依赖、Pack 表名和相关评论摘要会发送到你配置的 AI 服务。界面会显示该提示。
- **未启用 AI**：仅使用本地规则与工坊元数据，不发送任何内容到 AI 服务。
- **AI 失败或超时**：自动降级为本地规则结果，并在界面标记「AI 不可用」，不会丢弃已有建议。

## 排序规则

本地规则按以下优先级工作：

1. **硬依赖**：Pack 依赖必须先加载。工坊必需物品只作为软证据，不会强制采纳。
2. **类别顺序**：框架 → 大修 → 内容 → 视觉/UI/变体 → 补丁 → 语言包。
3. **资源覆盖**：共享 DB 表、脚本、本地化等资源时给出冲突提示；补丁排在目标内容之后。
4. **最小移动**：在满足约束的前提下，尽量保留当前顺序。
5. **稳定 tie-break**：同优先级按 Pack 文件名字节序，与默认加载顺序规则一致。

汉化 MOD 可能因为原 MOD 文本被写死而自带原 MOD 本体。如果工坊简介明确说明「包含本体」「includes the original」等，评估会忽略对应的工坊必需物品，不把它当成前置依赖；否则只给出软提示。

AI 只补充 `must_before` / `should_before` / `conflict` 关系；最终顺序仍由本地规则合并、检测环并生成。

MOD 超过 20 个时，除了每批 10 个的局部分析，还会执行**全局关系检查**：每批 40 个 MOD，并附带框架、大修、补丁、语言包等锚点，避免只看局部批次而漏掉跨批次关系。

## AI 重试

单次 AI 关系请求最多重试 **10 次**，使用指数退避（0.5 秒起，封顶 5 秒）。401/403、模型未配置等确定性错误不会重试。重试次数会显示在「统计」和「分析过程」中。

## 历史建议

每次完成的分析都会写入 `data/mod_order_history.json`，保留最近 50 条。记录包含：

- 排序基线与当前顺序
- 建议顺序、每个 MOD 的理由与置信度
- 冲突、警告、AI 是否降级
- 是否已应用及应用后的顺序

可以在弹窗内查看、应用或删除历史记录。应用历史记录同样只写入播放集和加载清单，不会订阅、启用或禁用任何 MOD。

## 防呆设计

- 分析、应用建议都不会订阅、启用或禁用任何额外 MOD。
- 缺失的工坊必需物品只显示警告，由用户自行判断是否订阅。
- 汉化 MOD 是否包含原 MOD 本体以工坊简介为准，不能仅凭必需物品字段判断。
- 应用建议只写入当前播放集和加载清单，不改动 MOD 文件。

## 限制

- 工坊简介和评论可能缺失或过期，此时建议主要依赖本地 Pack 内容。
- 评论是玩家报告，不是经过验证的兼容性结论；界面会将其作为提示而非硬约束。
- 资源冲突提示表示多个 MOD 覆盖同一资源，不一定代表一定不兼容。
- AI 分批分析本质上是局部的；全局检查只补充锚点相关的关系，不能保证覆盖所有两两组合。
- AI 的置信度是模型自报，不是校准过的概率。
- 分析不会修改游戏 Pack，也不会自动订阅、启用或禁用任何 MOD。
