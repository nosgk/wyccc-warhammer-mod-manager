# AI 智能排序

> 适用版本：`1.3.0` 及以后
> 入口：主界面底部「AI 智能排序」

## 功能说明

AI 智能排序会批量评估当前播放集中已启用 MOD 的建议位置，并给出：

- 建议顺序与每个 MOD 的当前位置、建议位置和移动方向。
- 每个建议的理由，例如依赖关系、类别顺序、资源覆盖或工坊评论中的兼容性提示。
- 同一 DB 表、脚本、本地化或 UI 资源被多个 MOD 覆盖时的冲突提示。
- 工坊必需物品缺失、AI 不可用等提示。

分析结果**不会自动应用**。只有点击「应用建议」后，才会写入当前播放集和加载清单。

## 数据来源

| 来源 | 用途 |
| --- | --- |
| 工坊元数据 | 标题、简介、作者、更新时间 |
| 工坊必需物品 | 建立依赖关系，依赖项排在依赖者之前 |
| 工坊评论 | 提取与加载顺序、兼容性、崩溃相关的摘要 |
| 本地元数据 | Pack 名、来源、更新时间、依赖、单位数据表 |
| Pack 索引 | DB 表、脚本、本地化、UI、变体资源 |
| 当前顺序 | 尽量少移动，保留用户手动调整的结果 |

## 使用方式

1. 在主界面启用需要评估的 MOD。
2. 点击底部「AI 智能排序」。
3. 点击「开始分析」。
4. 查看当前顺序与建议顺序、理由和冲突。
5. 点击「应用建议」写入当前播放集；或关闭窗口保留原顺序。

分析期间可以继续浏览 MOD。关闭窗口会取消正在进行的分析。

## AI 与本地规则

- **启用 AI**：MOD 名称、简介摘要、依赖、Pack 表名和相关评论摘要会发送到你配置的 AI 服务。界面会显示该提示。
- **未启用 AI**：仅使用本地规则与工坊元数据，不发送任何内容到 AI 服务。
- **AI 失败或超时**：自动降级为本地规则结果，并在界面标记「AI 不可用」，不会丢弃已有建议。

## 排序规则

本地规则按以下优先级工作：

1. **硬依赖**：工坊必需物品或 Pack 依赖必须先加载。
2. **类别顺序**：框架 → 大修 → 内容 → 视觉/UI/变体 → 补丁 → 语言包。
3. **资源覆盖**：共享 DB 表、脚本、本地化等资源时给出冲突提示；补丁排在目标内容之后。
4. **最小移动**：在满足约束的前提下，尽量保留当前顺序。
5. **稳定 tie-break**：同优先级按 Pack 文件名字节序，与默认加载顺序规则一致。

AI 只补充 `must_before` / `should_before` / `conflict` 关系；最终顺序仍由本地规则合并、检测环并生成。

## 限制

- 工坊简介和评论可能缺失或过期，此时建议主要依赖本地 Pack 内容。
- 评论是玩家报告，不是经过验证的兼容性结论；界面会将其作为提示而非硬约束。
- 资源冲突提示表示多个 MOD 覆盖同一资源，不一定代表一定不兼容。
- 分析不会修改游戏 Pack，也不会自动启用或禁用 MOD。
