# 联机模式验证

“联机模式”开关位于“启动记录”左侧，默认关闭，状态保存到启动器设置。开启时，普通启动、继续游戏和载入存档均只写入已启用 MOD 的加载列表，跳过启动器的单位数据、游戏数据、各类兼容补丁及运行选项 Pack 生成器。

Data 中已识别的启动器 Pack 会临时追加 `.wyccc-multiplayer-disabled` 后缀，避免 Movie Pack 自动加载。常规启动时恢复文件，并使用原有设置生成运行 Pack；保留原始 MOD 选择和补丁选项。重复联机启动及重新扫描后，已改名的启动器 Pack 仍保持禁用。无法暂停 Pack 时阻止游戏启动。

验证范围：后端启动集成回归、前端开关与多语言回归、Ruff、Vite 生产构建。浏览器使用真实 Vue 界面和模拟桥接数据，验证开关位置、点击状态与实际颜色；截图见 [multiplayer-mode-on.jpg](multiplayer-mode-on.jpg)。

结果：后端 142 项测试及 30 项子测试通过，前端 55 项测试通过；Ruff 和 Vite 构建通过。构建保留现有的 JavaScript 分块体积提示。
